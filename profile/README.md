# Manusights

Manusights is an AI pre-submission review for research manuscripts: a section-by-section critique, citation checks against scholarly databases, and severity-ranked fixes before you submit. Start with the free Readiness Scan at https://manusights.com.

## Open data
- [Journal intelligence dataset](https://github.com/Manusights/journal-intelligence-dataset): acceptance rates, review times and desk-rejection rates, with an evidence type on every figure (CC BY 4.0)
- [Retracted-citation study](https://github.com/Manusights/retracted-citation-study): retracted-reference rate in recent biomedical papers (CC BY 4.0)
- [Compass corpus](https://github.com/Manusights/compass-corpus): journal-fit predictor corpus and methodology
- [Citation metadata](https://github.com/Manusights/manusights-citation): how to cite Manusights (DOI 10.5281/zenodo.20072010)
